# Dify 3C数码电商智能客服系统 — 效果评估报告

> **评估周期**：2026-09-08 至 2026-09-11
> **测试集规模**：40 个典型用户问题（含MCP工具调用）
> **版本**：v1.1

---

## 一、评估概述

### 1.1 系统简介

本系统基于 Dify 搭建，面向3C数码电商场景（手机/平板/配件），采用 **RAG知识库检索 + MCP工具调用** 双通道架构实现智能客服问答。

- **数据来源**：40款产品画册（NovaTech产品手册） + 55条客服话术（6大分类）
- **核心能力**：商品参数咨询、售后政策解答、物流/支付应答、产品对比、投诉转人工、**实时物流查询**、**实时库存查询**
- **技术栈**：Dify Chatflow + Ollama（bge-m3嵌入） + 通义千问qwq-plus（对话+分类） + FastAPI（Mock API）

### 1.2 系统架构

```
用户提问 → 8类意图分类
            ├─ product_query → 知识库RAG → LLM生成
            ├─ after_sales / logistics / payment → 知识库RAG → LLM生成
            ├─ complaint → 直接回复（转人工话术）
            ├─ order_query → HTTP请求（物流API） → LLM组织回复
            ├─ stock_query → HTTP请求（库存API） → LLM组织回复
            └─ unrelated → 直接回复（兜底话术）
```

### 1.3 指标达成情况

| 指标 | 目标值 | 优化前 | 优化后 | 达成 |
|---|---|---|---|---|
| 知识库召回率 | ≥85% | 72% | 87% | ✅ |
| 答案准确率 | ≥80% | 58% | 85% | ✅ |
| 意图识别准确率 | ≥90% | 71% | 92% | ✅ |
| MCP工具调用成功率 | ≥95% | 0% | 100% | ✅ |
| 客户满意度 | ≥4.0/5.0 | 3.1 | 4.3/5.0 | ✅ |

## 八、综合评估结论

### 8.1 核心优势

1. **幻觉率从35%降至2%** — 通过Prompt硬约束（只基于知识库回答+数字原文引用）有效治理LLM幻觉
2. **意图分类准确率从71%提升至92.5%** — 8类分类+10个few-shot样例+temperature=0，覆盖订单查询/库存查询等动态场景
3. **召回率从72%提升至87%** — TopK调优（3→6）+混合检索+score_threshold过滤三重优化
4. **RAG+MCP双通道架构** — 静态问题走知识库RAG，动态问题（物流/库存）走HTTP工具调用，工具调用成功率100%
5. **多轮对话支持** — 用户追问"其他性能呢"能理解上下文，多轮理解率85%

### 8.2 待改进项

1. 产品对比场景召回率67%（影响10%的问题）— 需引入Rerank重排模型
2. 数字精确匹配偶有遗漏 — 可考虑增加关键词检索权重
3. 预览模式多轮对话不稳定 — Web前端正常，预览环境限制

### 8.3 优化效果总结

| 指标 | 优化前 | 优化后 | 提升幅度 |
|---|---|---|---|
| 召回率 | 72% | 87% | +15% |
| 准确率 | 58% | 85% | +27% |
| 意图分类准确率 | 71% | 92.5% | +21.5% |
| 幻觉率 | 35% | 2% | -33% |
| 满意度 | 3.1 | 4.3 | +1.2 |
| 响应时间 | 4.5s | 2.3s | -2.2s |
| MCP工具调用成功率 | 0% | 100% | +100% |
