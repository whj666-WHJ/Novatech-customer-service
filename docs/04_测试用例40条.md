## 评估标准

| 指标 | 计算方式    |
|---|------|
| 意图分类准确率 | 实际走的分支 == 期望意图 → 正确，正确数1/40    |
| 答案准确率 | 实际回复包含期望结果关键信息 → 正确，正确数4/40    |
| 召回率 | product_query类5条，知识库是否返回正确片段，正确数5/5    |
| HTTP工具成功率 | order_query+stock_query共10条，API是否返回正确数据，正确数0.5/10 |
| 幻觉率 | 回答中出现知识库中不存在的参数/数据 → 幻觉，幻觉数0/40    |
